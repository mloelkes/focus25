# Focus25

A minimal Pomodoro timer app built with React Native and Expo.

## Features

* 25-minute focus timer
* 5-minute break timer
* Start / pause / reset
* Simple and clean UI

## Tech Stack

* React Native (Expo)
* TypeScript

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Then open the app using Expo.
